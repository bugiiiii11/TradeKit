`docs/collab/landscape-v1/MERGE_NOTES_FROM_[me].md`, <=2 lines per note.

## Check

1. **Provenance** -- the coordinator's paste names specific tag claims to verify. For each: does the tagged
   seat's file actually say that? Any `[BOTH]` that is really one seat + a concession? Any `[merger]` content
   riding under a seat tag? Any red-team item used to justify a BUILD or EVALUATE row?
2. **Dispositions** -- exactly one per candidate; every BUILD has a scope, gate, capital and effort; every
   EVALUATE has a first step and a pass/fail gate with numbers; every MONITOR names its trigger; every CLOSED
   carries its numbers. Any row that is really "maybe"?
3. **Concessions** -- honoured as claimed in the Round 2 notes?
4. **Flip conditions** -- stated separately per row, with their kind (look-up fact / measurement / preference),
   not collapsed?
5. **Disputes** -- every `[DISPUTED]` survived both flip-checks "no"? Preferences re-classed as decisions for H?
6. **Drift / over-reach** -- framing that neither seat earned; a recommendation that is not traceable to a row;
   inflation (target <= ~15 candidate rows + a short decision table); the coordinator's declared prior leaking
   into untagged text.
